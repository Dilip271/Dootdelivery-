# DootDelivery

DootDelivery – Fast Local Delivery Website.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — product search and cart demo

## GitHub Pages
After uploading these files to the repository, enable GitHub Pages from:
**Settings → Pages → Deploy from branch → main → /(root)**

This is a starter website. Replace the demo products, contact email and delivery/order system with your actual business details.
